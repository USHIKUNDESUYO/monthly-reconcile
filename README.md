# 月次照合

帳簿と請求一覧を比べ、対応する候補と確認が必要な行を整理する無料の確認版です。元の行を確認して判断を記録し、入力と結果をJSON・CSVで保存できます。

ブラウザー内で処理する構成で、サーバー、AI、OCR、外部ライブラリを必要としません。同梱のHTMLをChromeまたはEdgeで開いて使います。最初は架空データで操作を確かめてください。

[確認版をダウンロード](https://github.com/USHIKUNDESUYO/monthly-reconcile/releases/tag/v0.1.0-preview.20261011-guided.3)

CSVの照合と調書の下書きのどちらから始めるかは、[月次照合とYUHITSUの使い分け・再現ガイド](GUIDE.md)で確認できます。

初めての方は[最初の1組を確認し、保存した記録を開き直す](START.md)へ進んでください。[同じ月の続きと翌月の始め方](NEXT_MONTH.md)、[利用後の任意の確認票](USAGE_REPORT.md)も用意しています。

## 最初の1組を確認して保存する

1. ZIPを展開し、`monthly-reconcile.html`を開きます。
2. 「架空データで試す」を押し、確認者IDを入力します。個人名を入れる必要はありません。
3. 「未記入の候補を1組確認する」を押します。帳簿と請求の元行、日付、相手先、金額を確認してください。
4. 判断と理由を入力します。候補を採用する場合は、両側を確認したチェックを入れて記録します。
5. JSONとCSVを両方保存し、保存先のファイルを確認します。JSONは続きから再開するために、CSVは一覧を確認するために使います。

再開する場合は「保存した記録を再開する」からJSONを選びます。読み込み中は、別のJSONの再開や入力の変更を止めます。読み込みに失敗した場合は、入力や再開の操作をやり直せます。判断が未記入の行や未解決の行も保存できます。確認が終わっていない行を、完了した取引として扱わないでください。

## 自分のCSVを使う

対象月と、帳簿・請求の2つのUTF-8 CSVを指定します。簡易CSVの列は`日付,相手先,金額`の順です。日付は`YYYY-MM-DD`、金額は通貨記号やカンマを付けない正の整数円にします。

標準CSVでは`row_id,invoice_date,party,gross_amount_jpy,source_file,source_row`の列を使えます。両側の金額を税込請求額にそろえてください。1ファイル300行・1MBまで読み込めます。

同じ日付・相手先・金額がそろい、両方向で相手が一つに決まる行を候補として表示します。欠損、曖昧な対応、重複、対象月外、返金、分割・合算などがある行は要確認です。法人表記の整理は初期状態で無効です。原資料で同じ法人だと確認した場合だけ設定を有効にしてください。

CSVの読み込みと照合処理が終わるまで、別のファイル選択、入力の編集、保存、入力の変更を止めます。CSVの読み込みに失敗しても入力を保ち、同じファイルを選び直せます。

## 保存先と確認範囲

JSONには元入力と判断履歴が含まれます。実データを保存する前に、保存先のクラウド同期や共有の設定を確認してください。CSVでは数式として解釈される可能性のある文字列にアポストロフィを付けます。元の値を保ったJSONも一緒に保存してください。

再開用JSONは4MB、変更履歴は10000操作までです。保存できない大きさになる変更は記録せず、直前の判断と履歴を保持します。入力ハッシュは入力の同一性を確認するための値です。資料の真正性や確認者の本人認証を保証するものではありません。

対象版は`0.1.0-preview.20261009`、画面は`guided.3`です。架空データによる判定・記録・保存の試験を実施しました。以前のguided.1では、開発者が直接起動、保存・再開とオフライン操作を確認したと報告しています。修正版guided.3の実ブラウザー画面、Safariとモバイル実機は未確認です。ソースからの再生成と試験の方法は[BUILD.md](BUILD.md)に記載しました。

この版で完了するのは資料の照合と判断の記録です。月次決算、税務申告、監査意見の完了を表しません。未解決の行は原資料と担当者に確認してください。
